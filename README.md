# Elixir qualification fixture

Generated test code, not a production extension or content source.

This tiny source-backed Live provider returns one synthetic channel and no
streams. It has no imports, media, artwork, external URLs, network requests,
credentials, setup inputs or persistent state. The three Live permissions are
required by Elixir's current provider contract; they do not grant generic
network egress. The runtime is capped at 64 MiB and 20% of one core.

Version 1.0.0 and a 1.1.0 metadata-only update are prepared to qualify source
matching, protected package/proof delivery, explicit installation and opt-in
updates. They do not qualify real media playback or migration of stored state.

The source uses a new disposable publisher identity. Signing keys and author
state are outside this source repository. No paid credentials are fabricated,
and no adoption gate is disabled.

This repository is currently LOCAL ONLY. It has not been published or seeded.
The owner must approve its public destination before any remote is configured
or files are uploaded. No company-operated seed/marketplace host is implied.
