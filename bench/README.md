# Cold-page qualification sources

Twenty generated metadata-only Live providers for measuring a complete 20-listing page. Each has its own extension ID and pinned source subdirectory, with the same small synthetic provider implementation as the original qualification sample.

They contain no media, real streams, artwork, external URLs, network requests, credentials or persistent state. They are test fixtures, not production content sources.

Publisher keys, signing ledgers, packaged releases, source proofs and simulated account/support records must remain outside this repository. Simulated support is confined to isolated tests, never production marketplace eligibility. Public source does not imply a searchable listing, paid adoption, package hosting or production readiness.
